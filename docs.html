Docs & Sitemap

Site map, feature overview, and references for the Standalone Playground.

Sitemap

All main pages. For search engines, use the XML sitemap: sitemap.xml. Replace YOUR_DEPLOYMENT_URL in sitemap.xml with your live site URL before deploying.

  • Home — Second brain hub, quotes, weather, focus timer, notes
  • Playground — Code runner (Python/JS/SQL), DevDocs, GitHub, search hub, JupyterLite
  • Trends — Hacker News, Inshorts, Wikipedia pageviews, filters
  • Resources — Courses, books, YouTube, GitHub, learning paths by topic
  • Tools — Word editors, notebook, backup/restore, PDF viewer
  • Jobs — Job listings (playground-serveless / job-search-api), filters, Binder notebook
  • System & API test — Cloudflare, Vercel, Railway, project APIs health checks
  • Docs — This page

Features overview

  • No backend — Static HTML/JS; free APIs and client-side runtimes (Pyodide, sql.js, JupyterLite).
  • Playground — Tech mode: DevDocs, GitHub, code runner. Non-tech: DuckDuckGo, Wikipedia, Stack Overflow, Word links.
  • Resources — Curated by topic (Data Analytics, ML, Data Engineering, BI, etc.) with courses, books, YouTube, GitHub.
  • Jobs — Powered by playground-serveless or job-search-api; set JOB_PROXY_URL in the Jobs page config.
  • Music bar & Video panel — YouTube and JioSaavn (global bar + right-side panel on supported pages).

APIs & integrations

  • Jobs — Configure JOB_PROXY_URL to point to your job API (e.g. playground-serveless or job-search-api).
  • OMDb (posters) — Set window.OMDB_PROXY_URL to your proxy (e.g. playground-serveless) so the API key stays server-side.
  • Analytics — Events sent to a configurable endpoint. System & API test page checks health and all endpoints.

System & API test page

Use test-analytics.html to verify that endpoints are reachable and working:

  • Cloudflare — Analytics Worker (health at /health), event ingest (/api/events), D1-backed dashboard (Basic auth).
  • Vercel — OMDb/CineMaterial proxy, jobs snapshot/cached APIs. Set OMDB_PROXY_URL in the site; test page uses it for OMDb and jobs checks. Testing ground: deploy api/omdb.js with OMDB_API_KEY.
  • Railway — Job-search-api (scrapers, RSS, local UI). Set JOB_PROXY_URL to your Railway app URL for jobs; test page can ping health/root.
  • Project APIs — Quotable, Animechan, Open-Meteo, Dictionary, Jikan, Wikipedia, Hacker News, Inshorts, TVMaze, Picsum, GitHub trending, Dev.to, etc. Each has a Test button to check connectivity from the browser.

Analytics debug: ?analytics_debug=1 or localStorage.setItem('analytics_debug','1') and DevTools Console.

Analytics (events)

Visit and unload events are sent from all main pages to the configured ingest URL. Dashboard is served by the same Cloudflare Worker (Basic auth protected).
