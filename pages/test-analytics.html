Cloudflare — Analytics Worker & D1

Our analytics: Worker (ingest + dashboard), D1 for event storage.

Worker base: —

Health check GET /health (uptime check) —
Ingest (events) POST /api/events — send visit/unload events —

Dashboard: same origin, Basic auth protected. See Docs for dashboard URL and credentials.

Vercel — APIs used by the project

e.g. playground-serveless: OMDb/CineMaterial proxy, job snapshot/cached. Set OMDB_PROXY_URL / JOB_PROXY_URL in the main site.

Proxy base: —

OMDb proxy GET /api/omdb?t=Inception — poster/search (needs API key on server) —
Jobs API GET /api/jobs-snapshot or /api/jobs-cached — job listings —

Testing ground: deploy your own Vercel project with api/omdb.js, set env OMDB_API_KEY.

Hugging Face (HF) — Job search API & UI

job-search-api: scrapers, RSS, local UI. UI pages can send site=railway-ui to analytics (legacy label).

Base URL: —

Jobs / health GET /health — job-search-api on Hugging Face (HF) —

Set JOB_SEARCH_API_BASE in the script above to your Hugging Face Space URL.
